# My-portfolio

Ghassan's portfolio site. Plain HTML, CSS and JS, no build step: open `index.html` or serve the folder.

- Add or edit works in `works.js` (cover image, screenshots and case study text).
- Every work card uses the same cover layout; hover only affects the card under the pointer.
- Case studies open at `#/work/<slug>` and follow the design's structure.
